Skill `usausa-ppt-unify-design`

**直すもの**
- 文字の大きさ：段階（10・12・14・16・20・24・32…pt）に近いものだけ揃えます。
- 図解：位置とサイズが数ミリずれているものを、中央値に揃えます。
- インデント：デッキ内で最も多い値に揃えます。
- 余白：余白・段落間隔・グリッド吸着は、指定があるときだけ行います。
- タイトル位置：表紙を除いて揃えます。

**中身は変えない仕組み**
- 変えるのは位置・サイズ・文字の大きさ・余白の数値だけで、文章・数値・ノート・図形の数と順序・色・フォント名は変えません。
- 実行後に、テキスト・ノート・図形の数と順序が元と同じか自動で検証します。不一致なら出力を使いません。
- 全ての変更は、Excel のログ（変更前・変更後）に残ります。

**Difyデッキでの試し結果**
- 変更は79件でした。位置・サイズの微調整が72件、文字サイズが7件です。中身は一致しました。
- 変更後のスライド5は、図解の崩れがないことを画像で確認しました。他のスライドは未確認です。
- 11pt・13pt・15pt・18pt は、段階（10・12・14・16…）の中間です。意図的な可能性があるため、自動では変えず「要手動確認」に出しました。11pt だけで54箇所あります。
- 最初は設定が強すぎて、約1600件も変更されて意図した余白まで崩しかけたため、許容差を0.03inに絞りました。
